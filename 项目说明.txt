115 网盘管理器 - 项目说明
============================

项目概述
--------
这是一个功能强大的本地 115 网盘管理工具，帮助用户高效整理和管理 115 网盘中的海量资源。

核心功能
--------
1. 目录浏览：浏览 115 网盘目录结构
2. 批量扫描：将云端目录同步到本地数据库
3. 一键转存：批量转存分享链接到网盘
4. 查重清理：找出并删除重复资源
5. AI 分类：使用 AI 识别资源类型
6. 标签管理：给资源打标签，方便筛选
7. 备份恢复：自动备份和手动恢复

技术栈
------
- 后端：Python 3.9+ + FastAPI
- 前端：纯 HTML/CSS/JavaScript
- 数据库：SQLite
- 网络：curl_cffi（Chrome TLS 指纹）
- 定时任务：APScheduler

快速开始
--------
1. 安装 Python 3.9+
2. 安装依赖：pip install -r requirements.txt
3. 配置 Cookie：创建 cookie115.txt
4. 启动服务：python server.py 或双击 启动115管理器.bat
5. 访问界面：http://127.0.0.1:8765
